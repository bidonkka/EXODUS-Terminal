<p align="center">Advanced PTY terminal emulator with enhanced features, built with PyQt5.</p>

![EXODUS Logo](./resources/icon.png)
 ## ✨ Features
| Features | Description |
|---------|------------|
| PTY emulation | Full pseudo-terminal support |
| Command history | Persistent history with timestamp |
| Color schemes | Matrix green, Amber, Blue, Red |
| Auto-completion | Supports command hints |
| Signal handling | Ctrl+C, Ctrl+Z, etc. |
| Logging | Session statistics & logs |

   | Requirements |
  |---------------------------------|
 | Python 3.11+                    |
 | PyQt5                           |
 | Linux (tested on Fedora/Ubuntu) |

Install dependencies:

```bash
pip install pyqt5
```
## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/bidonkka/EXODUS-Terminal.git

# Enter the project directory
cd EXODUS-Terminal/EXODUS

# Run installer
chmod +x install.sh
./install.sh
```
